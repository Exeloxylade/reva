# Automated-Lunch-Free CLI Starter Harness

`Automated-Lunch-Free` exposes code-callable CLI workflows via Electron/Node (`npm.cmd run make`, `npm.cmd run map`, `npm.cmd run style-test`, `node scripts/style-check.js`):

- Check style: `python run_bench.py check <style-id>`
- Run 8-beat gate: `python run_bench.py style-test <style-id>`
- Run map builder: `python run_bench.py map ...`
